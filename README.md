# 박현민 AI 오피스

현민님 전용 모바일 PWA. 나리·달이와 한 화면에서 지시하고 현황을 보는 1차 프론트엔드 버전입니다.

- 주소: https://onecutstudio3-lgtm.github.io/hyunmin-office/
- 구성: 정적 파일만 (index.html · manifest.json · sw.js · 아이콘)

## 설치 (Android 크롬 / 삼성 인터넷)

1. 위 주소를 폰 브라우저로 엽니다.
2. 메뉴에서 **홈 화면에 추가**를 누릅니다. (크롬은 주소창 오른쪽 ⋮ → 홈 화면에 추가)
3. 홈 아이콘으로 실행하면 주소창 없는 앱 화면으로 열립니다.

## 지금 되는 것

- 맵 / 회의실 / 대시보드 / 캘린더 / AI한도 / 메모 6개 탭
- 회의실: 대회의실 · 나리 1:1 · 달이 1:1, 지시 보내기 → 말풍선 즉시 추가 + 이 기기에 저장(localStorage)
- 메모장 저장, 절약 모드 토글, 하단 봇/대화/메모 내비게이션
- 오프라인 실행(서비스 워커 캐시)

## 아직 안 된 것

- **실시간 공용 DB 미연결.** 지금 보낸 지시는 이 브라우저에만 저장되고 나리·달이에게 실제로 전달되지 않습니다.
- 설정(⚙️ AI 서버) 시트에 Supabase URL/anon key를 넣어 두면 2차 버전에서 그대로 붙습니다. `window.OfficeDB` 어댑터가 연결 지점입니다.
- 첨부(+), 지난·다음 날 루틴, 실제 봇 응답은 2차 버전 범위입니다.
