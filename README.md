# 박현민 AI 오피스

현민님 전용 모바일 PWA. 나리·달이·제이·주노 네 명과 한 화면에서 지시하고 현황을 보는 오피스입니다.
2차 버전부터 **Supabase 공용 DB(hyunmin-office)** 에 대화·메모가 저장되고, 폰·PC·나리·달이·제이·주노가 같은 방을 실시간으로 봅니다.

- 주소: https://onecutstudio3-lgtm.github.io/hyunmin-office/
- 공용 DB: https://xwylmxghvlvhgizrjhqm.supabase.co (organization `OneCutStudio` / Free, 리전 ap-northeast-2 서울)
- 구성: 정적 파일만 (index.html · app.js · manifest.json · sw.js · 아이콘)

## 설치 (Android 크롬 / 삼성 인터넷)

1. 위 주소를 폰 브라우저로 엽니다.
2. 메뉴에서 **홈 화면에 추가**를 누릅니다. (크롬은 주소창 오른쪽 ⋮ → 홈 화면에 추가)
3. 홈 아이콘으로 실행하면 주소창 없는 앱 화면으로 열립니다.

## 지금 되는 것

- 맵 / 회의실 / 대시보드 / 캘린더 / AI한도 / 메모 6개 탭
- 회의실: 대회의실 + 1:1 네 개(나리 · 달이 · 제이 · 주노). 지시 보내기 → Supabase `messages` 에 저장 + 실시간 반영
- 말풍선마다 **[복사]** — 한 번 눌러 본문을 클립보드로(1.5초 “복사됨 ✓”)
- **[진행 현황]** 패널 — `memos` 의 글을 진행중/완료로 나눠 요약(접이식). `[완료]` 접두어로 완료 표시
- 메모: Supabase `memos` 에 저장, 공용 DB에서도 삭제
- 폰 화면 복귀(visibilitychange · focus · pageshow) 시 최신 글·메모를 바로 다시 불러오고 Realtime 구독도 점검·복구
- 하단 상태바: **공용 DB 연결됨 · 실시간 동기화** (Realtime 실패 시 5초 폴링으로 자동 전환)
- 오프라인 실행(서비스 워커 캐시) + 연결이 끊기면 이 기기에 보관했다가 다시 올림
- 설정(⚙️ AI 서버) 시트에서 다른 Supabase 프로젝트로 바꿀 수 있음 (anon 공개 키만)
- **⚡ 즉시 채팅(Gemini)** — 헤더 `⚙️ AI` 시트에 Google Gemini API 키를 넣으면, 지시를 보낸 순간 브라우저가 Gemini를 직접 호출해 2~5초 안에 답합니다. 1:1 방은 그 봇 한 명이, 대회의실은 네 명이 3단계 협의(1차 의견 → 2차 보완 → [최종 결론])를 0.5초 간격으로 올립니다. 키는 `localStorage`에만 저장되고 저장소에는 절대 들어가지 않습니다.

## 배포 방법

GitHub Pages가 이 저장소에서 `gh-pages / (root)`로 설정되어 있습니다.
수정 후에는 `./deploy.sh` — `main`을 올리고 `gh-pages`를 `main`에 맞춰 밀어 올립니다.

## ⚡ 즉시 채팅 (Gemini) 사용법

1. 폰 브라우저에서 사이트를 연 뒤 상단 **⚙️ AI** 를 누릅니다.
2. 아래 **⚡ 즉시 채팅 (Gemini)** 칸에 Google AI Studio에서 발급한 API 키(`AIza…`)를 붙여넣고 **키 저장** 을 누릅니다. 저장과 동시에 즉시 채팅이 ON 됩니다.
3. **연결 테스트** 로 키가 살아 있는지 먼저 확인합니다. 성공하면 `✅ Gemini 연결됨`, 실패하면 이유가 그대로 뜹니다.
4. 회의실에서 지시를 보내면 상단 배지가 **⚡ 즉시 채팅 ON** 으로 바뀌고, 보낸 즉시 답변이 올라옵니다.
   - 1:1 방(나리·달이·제이·주노): 해당 봇 1명이 최근 대화 10건을 보고 답합니다.
   - 대회의실: 네 명이 3단계 협의를 한 번에 만들어 4~6개 말풍선으로 차례로 올립니다(API 호출 1회).
5. 다시 5분 서버 답변으로 돌아가려면 시트의 **즉시 채팅** 토글을 끄면 됩니다. **키 삭제** 는 이 기기에서만 지웁니다.

- 무료 등급(Gemini API Free tier)으로 씁니다. 한도를 넘으면 말풍선 아래에 안내가 뜨고 DB에는 아무것도 남기지 않습니다.
- 키는 **브라우저별 저장** 입니다. 폰에서 넣은 키는 PC에 없으니 PC에서도 한 번 넣어야 합니다.
- 즉시 답변이 달린 글에 5분 감시 피클이 나중에 한 번 더 답할 수 있습니다. 실제 실행이 필요할 때는 피클 채팅에서 따로 요청하세요.

## 보안 메모

- 프론트엔드에는 **anon(공개) 키만** 넣습니다. `service_role` 비밀 키는 절대 넣지 않습니다.
- `messages`·`memos` 는 RLS를 켜고 anon 역할에 SELECT/INSERT/DELETE 정책을 준 상태입니다(개인·비서 공용 오피스 설계).
  즉 사이트 주소를 아는 사람은 이 방을 읽고 쓸 수 있습니다. 더 조이려면 `room_key` 같은 한 겹을 추가하면 됩니다.
- DB 비밀번호는 프로젝트 생성에만 쓰고 코드·저장소에 넣지 않았습니다.
